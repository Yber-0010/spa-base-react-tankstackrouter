# base react with tankstack router

in this proyect I use method createRouter in tankStackRouter for path /, but when you need serv in /other path you can use createHashHistory.

- with 
react v19.2
tankStack router v1.161

- with bun
install
```bash
bun install
```


- before create .env.dev from .env.example
run
```bash
bun run dev --mode dev
```

build
```bash
bun run build
```
